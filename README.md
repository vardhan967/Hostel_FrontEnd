## Roomie Nest UI

A Vite + React + TypeScript project with Tailwind CSS and shadcn-ui components.

### Development

Requirements: Node.js 18+ and npm.

```sh
npm install
npm run dev
```

### Build

```sh
npm run build
npm run preview
```

### Environment

- Create a `.env` file with:
	- `VITE_API_BASE_URL=https://vardhan.pythonanywhere.com/api`

### Tech stack

- Vite
- React 18
- TypeScript
- Tailwind CSS
- shadcn-ui
